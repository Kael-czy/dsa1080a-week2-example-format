# DSA 1080A - Week 2 Example / Template (Format Reference Only)

## What this repo is

This is an **EXAMPLE / TEMPLATE** repository showing the general format and approach for a typical **Week 2 (Exploratory Data Analysis / Data Cleaning)** phase of a data science group project, in the style of the DSA 1080A Group 10 "Sky Server" star classification project.

It is for **reference only** — it demonstrates structure, not results. Write your own analysis, using your own group's real data and your own real findings, in your actual submission repository (`dsa1080a-group10-space-observation`).

## Why this exists

Week 1 of the real project (done separately, in the real group repo) covered loading the dataset and basic exploration: shape, info, describe, null checks, and a class-distribution plot.

Week 2 in this kind of project is typically the deeper EDA / cleaning phase: handling missing values and outliers, exploring correlations between features, visualizing distributions per class, and looking at feature-target relationships, followed by a short written summary of findings.

## Important notes

- The notebook in this repo uses a **representative / illustrative** dataset shape similar to the "Sky Server" star classification dataset (photometric bands, redshift, class label), not the group's actual file.
